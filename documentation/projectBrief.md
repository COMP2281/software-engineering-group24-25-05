# Project Brief: CounterSpy Game with IBM Skills Build Integration

## Problem Statement

Design an engaging educational game based on CounterSpy. The objective of the game is to retrieve stolen plans for a brand new artificial intelligence system. The game will incorporate AI (for question difficulty and boss interactions) to quiz the players on IBM Skills Build questions. This project aims to make IBM Skills Build more interesting and encourage players to learn.

## Problem Specifics

1. Educational Integration: The game should seamlessly integrate educational content from IBM Skills Build badges, making learning a core part of the gameplay.
2. Immersive Experience: Use Artificial Intelligence (doesn't need to be ChatGPT) to personalise the difficulty of questions based on player performance, perhaps use it for boss-level interactions.
3. Engagement and Motivation: Design game mechanics that motivate players to learn and improve their Artificial Intelligence, Cybersecurity, and Data Analytics skills.
4. Interdisciplinary Collaboration: Encourage collaboration among students from various disciplines, including computer science, design, education, and business.

## Target Audience:

- Age Range: 16+
- Language: English
- Interested in AI, Cybersecurity, and data analytics

## Product / Service Requirements (High Level)

1. Game Design

   - Theme: Based on CounterSpy, a Cold War-era stealth game.
   - Gameplay: Side-scrolling stealth game where players infiltrate enemy bases to prevent nuclear launches.
   - Boosts and Card Quality: Players earn boosts and improve card quality by answering questions from IBM Skills Build badges integrated into the game.

2. Educational Content:

   - Base questions and answers from the IBM tutorials in IBM Skills Build
   - Adaptive Learning: Implement AI to adapt the difficulty of questions based on the player’s progress and performance.

3. Technical Requirements:

   - AI Algorithms: Use AI to personalise the learning experience and adapt gameplay.

4. User Interface and Experience:

   - Intuitive UI: Design an intuitive and user-friendly interface.
   - Engaging Visuals: High-quality graphics and animations to enhance the gaming experience.

## Expected Output

1. Game Prototype: A working prototype of the CounterSpy game with integrated educational content.
2. Question Bank: A comprehensive and categorised question bank from IBM Skills Build badges (Artificial Intelligence, Cybersecurity, and Data Analytics).
3. User Testing Report: Summary of user testing results, including feedback and iterations made.
4. Final Presentation: A presentation showcasing the project, including a live demonstration of the game.
